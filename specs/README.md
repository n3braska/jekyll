# Specs

Feature specifications for this site. Each feature gets its own folder named `J-<n>`, numbered in order of creation.

| ID  | Title                                  | Status |
|-----|----------------------------------------|--------|
| [J-1](J-1/spec.md) | Word timetable import into the admin panel | Implemented, not deployed |

## Conventions

- `J-<n>/spec.md` is the main document: problem, current state, proposal, open questions, acceptance criteria.
- Supporting material (sample outputs, diagrams, notes) lives next to it in the same folder.
- Status values: `Draft` → `Agreed` → `Implemented` → `Done`.
